1. Introduction

Welcome to Anh Đạt Dz Vcl, a Discord bot designed to provide automated features and interactive functionality within Discord servers.

We respect user privacy and are committed to transparency regarding how information is processed when users interact with our bot.

2. Information We Process

The bot may temporarily process information provided through the Discord API when necessary to perform its functions.

Depending on the features used, this information may include:

  • Discord user IDs
  • Discord server IDs
  • Member-related information
  • Commands submitted to the bot
  • Message content required for command processing
  • Presence information, if applicable

3. Data Storage

Anh Đạt Dz Vcl does not intentionally maintain a persistent database of personal user information.

Information required to execute commands or provide bot functionality is processed temporarily.

The bot does not intentionally retain message content, presence information, or personal user information for long-term storage.

4. Message Content Intent

If Message Content Intent is enabled, the bot may access message content when necessary to recognize supported commands and respond to user requests.

Message content is not used for advertising, user profiling, or AI model training.

5. Server Members Intent

If Server Members Intent is enabled, the bot may process member-related events and information necessary for supported server functionality.

This information is not intentionally retained in a persistent user database.

6. Presence Intent

If Presence Intent is enabled, the bot may temporarily process presence information required for supported features.

Presence information is not intentionally stored for long-term tracking.

7. Data Sharing

We do not sell personal information or share user data with advertisers.

Information may be processed by Discord and the infrastructure providers necessary to operate the bot.

8. Data Security

We take reasonable measures to protect information processed by the bot.

Access to the bot's infrastructure is restricted to authorized operators.

9. User Rights

Users may contact the developer to ask questions about data processing or request deletion of any information that may be retained.

Since the bot does not intentionally maintain a persistent database of personal user information, there may be no stored personal data to delete.

10. Children's Privacy

The bot is intended for users who meet Discord's minimum age requirements.
